## 常见问题

### Rescot 是什么？

Rescot 是一款桌面 AI 智能体，能读写本地文件、运行命令，并连接你自己的模型与 GPU 服务器。它免费、无应用内购买，仅支持 Windows x64（Windows 10 build 17763 及以上 / Windows 11），最新版本 1.10.2，发布于 2026-10-22。

- 1.10.2 没有 macOS 版，最后一个 macOS 构建是 1.8.72
- 需要 1 个账号（邮箱或第三方登录）才能使用

### Rescot 能接哪些模型？

Rescot 内置 13 家模型服务商，另有 1 个自定义 OpenAI 兼容端点，并支持 2 种运行在 127.0.0.1 的本机模型运行时。模型费用由你自己的模型服务商按用量收取，Rescot 收 0 元。

- 未填自有 API Key 时，消息会经 auth.learningfind.com 代为调用模型，并非纯本地链路
- 具体支持的服务商名单未在已知事实中列出

### 不想把文件交给云端的人，选 Rescot 时要注意什么？

Rescot 的 Full Access 分三档，范围分别是工作区、挂载目录、全盘，可按需收紧权限；本机模型运行时 2 种，地址在 127.0.0.1。但若未填自有 API Key，消息会经 auth.learningfind.com 路由调用模型，数据保留至用户请求删除或我方清除，请求 30 天内处理。

- 要完全避免第三方路由，需自备 API Key 或使用本机运行时
- 广告与第三方统计 SDK 为 0，但这不等于全链路离线
